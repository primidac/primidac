# Primidac Technology — Website Rebuild

## 1. Project Overview

Rebuild the Primidac Technology website from the ground up using **Astro**.

The website should represent **Primidac Technology as a registered business**, not as a limited company, corporation, agency, startup, or large organization.

Primidac Technology is a technology business focused on:

> **Building practical digital tools that empower businesses.**

The website should sit between a **professional product portfolio** and a **small technology business website**.

It should communicate three things clearly:

1. **Primidac builds useful software products and tools.**
2. **Primidac provides product engineering and technical capabilities.**
3. **Primidac publishes useful knowledge around software, tools, security, product design, engineering, and technology.**

The site should also establish the founder/operator as a **Product Engineer** without making the entire website a personal portfolio.

---

# 2. Core Positioning

## Primary positioning

**Primidac Technology builds tools that empower businesses.**

The business should be presented as a focused technology business that designs and builds software products, tools, and digital systems.

Do not position Primidac as:

- A generic software development agency
- A digital marketing agency
- A consultancy that does everything
- A huge technology corporation
- A venture-backed startup
- An AI company
- A Web3 company
- A fintech company exclusively

AI, Web3, fintech, security, automation, etc. are technologies/domains that may appear in products and projects.

They are **not the primary identity**.

The primary identity is:

> **Product engineering and building useful technology.**

# 6. Website Goals

The website has five major goals.

## Goal 1 — Explain Primidac

A visitor should understand what Primidac does within approximately 10 seconds.

## Goal 2 — Showcase products and tools

Products and tools should be a major section of the website.

The business should demonstrate that it actually builds things.

## Goal 3 — Showcase engineering capability

Visitors should understand that Primidac is capable of designing and engineering real software systems.

## Goal 4 — Publish knowledge

The website should contain a high-quality technical/product publication covering topics such as:

- Software engineering
- Product engineering
- Product design
- Security
- Developer tools
- AI
- APIs
- Architecture
- Automation
- Web development
- Technology decisions

## Goal 5 — Create a professional point of contact

Businesses or individuals interested in working with Primidac should have a simple way to initiate contact.

# 32. Motion

Motion should be subtle.

Use animation for:

- Page transitions
- Hover states
- Navigation
- Product cards
- Scroll reveals

Avoid:

- Long animations
- Constant movement
- Distracting parallax
- Excessive bouncing
- Animation on every element

The principle:

> **Motion should explain interaction, not decorate the page.**

Respect:

```text
prefers-reduced-motion
```

---

# 33. Astro Architecture

Use **Astro** as the primary framework.

The website should remain mostly static and content-driven.

Use Astro's strengths:

- Static generation
- Content collections/content layer
- Islands architecture
- Minimal client-side JavaScript
- Component-based architecture
- Excellent performance

Avoid adding React/Svelte/Vue unless there is a genuine requirement.

The default should be:

> **Astro components first.**

# 41. Accessibility

The website must target strong accessibility.

Requirements:

- Semantic HTML
- Keyboard navigation
- Visible focus states
- Proper heading hierarchy
- Accessible forms
- Labels for inputs
- Alt text
- Sufficient color contrast

# 42. Performance

Performance is a priority.

Use Astro's static-first architecture.

Requirements:

- Minimal JavaScript
- Optimized images
- Responsive images
- Lazy-load non-critical images
- Avoid unnecessary dependencies
- Avoid large client-side bundles
- Use modern image formats where appropriate
- Preload only genuinely critical assets
- Avoid blocking scripts

Target excellent Core Web Vitals.
